# Shadowrun — довідка для дизайну кіберпанк-глави Wilds

Зібрано з відкритих джерел (Shadowrun Wiki/Fandom, Wikipedia, shadowrunsixthworld.com,
TV Tropes, ігрові гайди) для аналізу перед проєктуванням кіберпанк-розширення Wilds.
Це довідковий матеріал, не специфікація — рішення, що саме переносимо, ухвалюємо окремо.

## 1. Сеттинг: «Шостий світ»

- Дія відбувається в майбутньому (тарґетний рік у Shadowrun Returns — 2054; у пізніших
  редакціях таблетопу — 2088). Кіберпанк + міська фентезі-магія.
- **Пробудження (Awakening), 2011.** Магія повертається на Землю. Хвиля «Unexpected
  Genetic Expression» (UGE) породжує перших ельфів і гномів; за 10 років, під час
  «Ґоблінізації», з'являються орки й тролі.
- Дракони можуть набувати людської подоби й керують мегакорпораціями.
- Світ фрагментований: корпоративні території з екстериторіальністю, міста-держави,
  корінні народи повернули собі частину земель через магічні ритуали.
- **Матриця** — всесвітня комп'ютерна мережа; з дротової (до 2029, «Crash») стала
  бездротовою й повсюдною.
- **Джерела:** [Wikipedia: Shadowrun](https://en.wikipedia.org/wiki/Shadowrun),
  [Shadowrun Wiki: Metahumanity](https://shadowrun.fandom.com/wiki/Metahumanity),
  [The Sixth World](https://shadowrunsixthworld.com/the-sixth-world/).

## 2. Раси (метатипи) — саме те, що просив користувач додати

П'ять основних метатипів («метагуманість»):

| Раса | Особливості |
|---|---|
| **Людина** | база, найчисленніша; універсальна, без спецбонусів/штрафів |
| **Ельф** | спритніші й харизматичніші за людей; сутінковий зір (low-light vision) |
| **Гном (дворф)** | витриваліші, сильніші, вольовіші; термографічний зір; повільніші; стійкіші до хвороб |
| **Орк** | ~1.9 м, кремезні, значно міцніші й сильніші, менш харизматичні; сутінковий зір; ікла |
| **Троль** | ще вищі й масивніші за орків; роги, кальцієві нарости на суглобах, нелюдський вигляд |

Додатково:
- **Метаваріанти** — локальні підвиди основних п'яти (гноми/«gnomes» окремо від дворфів
  у деяких редакціях, велетні, мінотаври тощо).
- **SURGE (Sudden Unexplained Regressive/Genetic Expression)** — подальші мутації:
  «змінені» (changelings), екзотичні риси III класу (людина-кіт, людина-ящір,
  людина-птах). Дає простір для процедурно згенерованих унікальних персонажів.
- **Заражені (Infected)** через вірус HMHVV — вампіри, упирі (ghouls): небезпечні,
  здебільшого антагоністи/варіант «прокляття».
- **Інше грайобельне:** перевертні (shapeshifters), сасквотчі, пікові феї (pixies),
  дракони, вільні духи, ШІ (ці — вже екзотика high-power кампаній).
- **SIN (System Identification Number)** — цифрове громадянство/ідентифікація.
  Орки й тролі частіше «SINless» (без ідентифікації) через дискримінацію; це створює
  соціальну напругу й причину, чому люди йдуть у тіньові оперативники.
- **Джерела:** [Shadowrun Wiki: Orks](https://shadowrun.fandom.com/wiki/Orks),
  [Metatypes](https://shadowrun.fandom.com/wiki/Metatypes),
  [SURGE/metagenic qualities forum summary](https://forum.rpg.net/threads/shadowrun-rewrite-metahumanity-and-racial-allegory.893509/).

| Архетип | Суть |
|---|---|
| **Street Samurai** | важке кіберобладнання, фізичний бій, «міський хижак» |
| **Decker/Hacker** | зламує Матрицю: краде дані, вимикає охорону, відкриває шлях команді |
| **Rigger** | нейроінтерфейс керує дронами й транспортом |
| **Mage** | плете закляття, викликає духів, шпигує астрально, лікує/атакує |
| **Shaman** | різновид мага, прив'язаний до природних сил, підтримка+виклик духів |
| **Adept** | магія спрямована всередину — довершує тіло до бойової досконалості |
| **Mystic Adept** | гібрид мага й адепта |
| **Face** | харизматичний перемовник, веде зустрічі з Мр. Джонсоном, торгується |

## 4. Кіберобладнання, біовеа, Essence

- Кожен персонаж має **Essence = 10** на старті. Кожен імплант (кібервеа) знижує це
  число; довести Essence до 0 = смерть. Сумарна вартість імплантів не може перевищити 9.9.
- **Чотири класи якості** кібервеа: basic → alphaware → betaware → deltaware (вищий клас
  = менша втрата Essence, вища ціна).
- Втрата Essence **незворотна**, навіть якщо імплант потім видалити.
- Втрата Essence зменшує магічний потенціал: кількість доступних слотів заклять ≈
  Essence/2 (округлено вниз); кожна втрачена одиниця Essence додає +1 до відкату заклять.
- **Біовеа** дешевша по Essence, дорожча грошима; у таблетоп-правилах не витрачає
  Essence взагалі, але теж впливає на магію.
- **Дизайнерська дилема, яку легко перенести:** «більше кіберсили = менше магії/душі» —
  готовий компроміс для будь-якої прокачки нашого героя.
- **Джерела:** [Essence wiki](https://shadowrun-series.fandom.com/wiki/Essence),
  [Cyberware wiki](https://shadowlandsl.fandom.com/wiki/Cyberware).

## 5. Магія

- Три шляхи: **Magician** (зовнішня магія — заклинання, виклик духів), **Adept**
  (внутрішня магія — підсилення тіла), **Mystic Adept** (гібрид).
- **Sorcery** ліпить ману в заклинання; дія триває, поки її «підживлюють» (маною
  чарівника, фокусом, духом).
- **Астральний простір/проекція**: маг може відділити астральну форму від фізичної й
  рухатися «зі швидкістю думки», недоступно фізичним бійцям без ініціації.
- **Духи**: викликані духи винні «послугу» за кожен успіх виклику; тип послуги залежить
  від виду духа й його сили (Force).
- **Традиції**: герметична, шаманська (норвезька, вуду, синто тощо) — по суті
  «скіни» одного магічного каркасу під різні культури/естетику.
- **Джерела:** [Magic wiki](https://shadowrun.fandom.com/wiki/Magic),
  [Astral Space](https://shadowrun.fandom.com/wiki/Astral_Space).

## 6. Матриця / хакінг

- **Декер** використовує кіберколоду (cyberdeck), щоб «зайти» в Матрицю; сучасні хакери
  можуть обходитись комлінком.
- **Rigger** керує дронами/транспортом через нейроінтерфейс («control rig»).
- **ICE (Intrusion Countermeasures Electronics)** — захист вузлів:
  - *White ICE* — шкодить лише аватару в Матриці (найпоширеніше);
  - *Black ICE* — може завдати шкоди й реальному тілу хакера («флетлайн»).
- Матричні контракти — найдорожчі (6000+ нуєн за раз) у Shadowrun Returns.
- **Джерела:** [Decking wiki](https://shadowrun-series.fandom.com/wiki/Decking),
  [TheGamer: Matrix tips](https://www.thegamer.com/shadowrun-trilogy-dead-mans-switch-dragonfall-hong-kong-matrix-combat-stealth-hacking-decking/).

## 7. Мегакорпорації («Велика десятка»)

Ares, Aztechnology, Evo, Horizon, Mitsuhama, Renraku, Saeder-Krupp, Shiawase,
Spinrad Global, Wuxing. Приклади:
- **Ares Macrotechnology** — зброя, авто (GM), космос; володіє охоронною Knight Errant.
- **Aztechnology** — товари, хімія, магія; з Ацтлану (колишня Мексика).
- **Renraku** — комп'ютери й зброя, Японія, «жорстке» розуміння честі.
- **Saeder-Krupp** — найбільша корпорація світу, очолювана драконом; сталь, авто (BMW),
  зброя.
- Корпорації рейтингуються A/AA/AAA за активами й прибутком; **AAA regulate тільки
  Corporate Court** (асамблея 10 AAA-корпорацій) — вони по суті понад законом держав.
- **Екстериторіальність**: корпоративна земля юридично суверенна, імунна до
  національних законів.
- **Джерела:** [The Sixth World](https://shadowrunsixthworld.com/the-sixth-world/),
  [Corporations wiki](https://shadowrun.fandom.com/wiki/Corporations).

## 8. Тіньові оперативники, фіксери, «раноки» (runs)

- **Мр. Джонсон** — узагальнена назва замовника рану (від боардрум-хижаків до вуличних
  темних ділків); часто анонімний/під псевдонімом.
- **Фіксер** — посередник між тінню та рештою суспільства: організовує зустрічі з
  Мр. Джонсоном, дає контакти (за гроші), знає секрети (особи Джонсонів/раннерів),
  але не ділиться ними — секретність частина його послуг.
- Кожен Джонсон пропонує кілька типів ранів за оплату; підручник **«Mr. Johnson's Little
  Black Book»** — довідник локацій і контактів для гейммайстрів.
- **Джерела:** [Fixer wiki](https://shadowrun.fandom.com/wiki/Fixer),
  [Mr. Johnson's Little Black Book](https://shadowrun.fandom.com/wiki/Source:Mr._Johnson's_Little_Black_Book/Summary).

## 9. Гроші, спорядження

- Валюта — **нуєн (¥)**.
- Категорії спорядження: зброя/боєприпаси/аксесуари, вибухівка, одяг і броня,
  побутові речі, стеження й охоронне обладнання, кіберімпланти, кіберколоди й
  програми, магічне спорядження, транспорт і дрони.
- Транспорт/дрони описуються характеристиками: Handling, Speed, Accel, Body, Armor,
  Signature, Pilot/Autonav, Seating, Load.
- **Джерело:** [Gear index](https://www.shadowrun2e.com/gear.html).

## 10. Злочинний світ / фракції вулиці

- Чотири міжнародні синдикати: **Мафія, Якудза, Тріади, Сеульпа-ринги** (корейські).
- **Ґо-банди (Go-Gangs)** — вуличні мотобанди (50+ учасників), часто «м'язи» для
  мафії/якудзи; у Сіетлі — Red Rovers, Eye-Fivers, Spikes, Leather Devils,
  405 Hellhounds, кожна тримає свою автостраду/територію.
- Це готовий каркас фракцій із різним стилем: корпоративний (SIN, легальність) проти
  вуличного (територія, честь, помста) проти організованого (структурований дохід,
  ієрархія).
- **Джерела:** [Go-Gangs wiki](https://shadowrun.fandom.com/wiki/Go-Gangs),
  [Yakuza wiki](https://shadowrun.fandom.com/wiki/Yakuza).

## 11. Структура ігор Shadowrun Returns / Dragonfall / Hong Kong

- **Хаб + місії.** Гравець повертається на базу (бар/сховище) між завданнями, наймає/
  спілкується з контактами, купує спорядження, тоді бере наступний ран.
- **Діалоги зі skill-checks.** Репліки відкриваються за навичками (наприклад,
  Etiquette: Security для проходу повз охорону; Etiquette: Shadowrunner/Socialite —
  різні винагороди залежно від того, як гравець себе подає).
- **Бій — покроковий тактичний**, з укриттям: базово 2 очки дій (Action Points) на хід,
  пізніше 3; кожна дія (рух, постріл, перезарядка, закляття, предмет) коштує AP;
  укриття (легке/важке) впливає на шанс влучання; дальність руху залежить від
  залишку AP.
- **Прогрес — карма** (Karma): очки витрачаються на будь-яку навичку/здібність, без
  жорсткої «класової» прив'язки.
- **Компаньйони** з власними арками: у Dragonfall — Дітріх (шаман), Глорі (кіборг),
  Айгер (тролль-зброяр), декер Бліц; у Hong Kong — Дункан (охорона), Ґоббет (шаман),
  Ізобель (декер), Рактер (ріггер), Ґайчу (Червоний самурай). Рішення гравця під час
  гри відкривають унікальні здібності компаньйонів або приєднують нових персонажів
  пізніше (наприклад, вампірка, яку можна тимчасово повернути в команду, якщо їй
  раніше допомогли).
- **Джерела:** [Shadowrun Returns wiki](https://shadowrun.fandom.com/wiki/Shadowrun_Returns),
  [Wikipedia: Shadowrun Returns](https://en.wikipedia.org/wiki/Shadowrun_Returns),
  [Companions — Dragonfall](https://www.gamebanshee.com/shadowrundragonfall/companions.php),
  [Hong Kong characters](https://shadowrun-series.fandom.com/wiki/Shadowrun:_Hong_Kong_characters).

## 12. Що з цього найлегше й найважче переносити в автономний («акваріумний») Wilds

Це лише спостереження для наступного обговорення, не рішення:

**Легко переноситься (текстове/наративне, вже схоже на наш рушій):**
- Раси/метатипи як варіанти генерації героя — вплив на статистики й опис, як зараз
  `Kind` для істот чи `ItemInfo` для предметів.
- Есенс/кібервеа як ще один ресурс поруч із HP/потребами: інсталяція імпланту дає бонус,
  але коштує «Essence» → природна дилема продовжити традицію «сила ціною чогось».
  Схоже на дилему «обігрів vs заряд маяка», яку ми вже маємо.
  вже маємо для капсули.
- Фіксер/Мр. Джонсон/контракти = пряме продовження вже наявного патерну
  «дія `enter` у локацію з ціллю → лут/нагорода», тільки тепер із виданою LLM ціллю
  (брифінг) і оплатою в нуєнах замість артефактів.
- Фракції/репутація — розширення того, що вже є для Ліри (`trust`/`affinity`), але на
  рівні угруповань, а не однієї людини.
- Дрони/охорона корпорацій — пряма заміна поточної фауни (`hound`/`brute`/`drone`/
  `android`), просто інша тема одягу.

**Складніше / потребує нового шару:**
- **Тактичний бій з укриттям і Action Points** — розрахований на покрокове керування
  гравцем; наш бій зараз спрощений (`hunt`/`fight`, авто-розв'язання). Перенести
  «дух» (укриття, дальність, різні типи зброї) можна без залучення гравця, як
  розширення того ж авто-бою.
- **Матриця/декінг** — окрема міні-гра в оригіналі; для автономного героя це або
  ще один «намір» з детермінованим міні-симом (шанс успіху від навички + ризик
  Black ICE), або відкласти на далі.
- **Магія (заклинання/духи/астрал)** — цікава, але третя незалежна система з нуля;
  варто вирішити окремо, чи вона взагалі потрібна в нашому кіберпанку (можна лишити
  чистий кіберпанк без магії, «Shadowrun без Awakening»).
- **Skill-check діалоги** — у нас діалог зараз повністю пише LLM без явних навичок;
  можна ввести приховані «навички репутації» (наприклад, Street Cred), які змінюють
  тон/варіанти, які бачить LLM, без окремого UI вибору гравця.
