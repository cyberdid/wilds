# Wilds: Тау-7

ASCII sci-fi виживання, у якому **живе ШІ**. Рятувальна капсула колоніального корабля
розбилася на незвіданій планеті Тау-7. Єдиний вцілілий сам вирішує, що робити, а ви лише
спостерігаєте: його думки, щоденник і розмови видно в реальному часі.

```
^^^,,ΨΨΨ..~~~~       Сол 3, 21:14 ☾  напруга 0.62 · наростання
^^,ΨΨ@Ψ...~~~~       здоров'я ██████████░░░  87
^,.%..x..Ø.,~~       Капсула: ⚡54 · обігрів ON · маяк: alloy 2/3, circuit 1/1
...▣....@..*∩.       Ліра: збирає волокно · довіра 0.62
                     ⚠ зграя ксенопсів: за ~95 хв
                     Мета: Знайти останній сплав у Вулику предтеч
                     «Виття ближче. Залишусь біля капсули, поки не розвидніється.»
```

## Історія, яка складається сама

- **Мета й фінал.** Аварійний маяк капсули `Ø` пошкоджено. Треба знайти 3 сплави обшивки
  й плату предтеч (в уламках кораблів `▣` або серед орбітальних уламків), зарядити капсулу
  до 80 і передати сигнал лиха. Шатл прилетить через 3 соли, якщо герой доживе.
- **Енергія як дилема.** Обігрів капсули гріє й відлякує звірів, але розряджає батарею.
  Сонячні панелі заряджають її лише вдень, енергоелементи дають +15.
- **Режисер Director-7** (без ШІ) міряє напругу й веде цикл
  «затишшя → наростання → пік → перепочинок». Події: пилова буря, падіння орбітальних
  уламків, зграя ксенопсів, збій капсули, сигнал SOS. Кожна подія **заздалегідь
  попереджає** про себе, тож смерть буває заслуженою, а не випадковою.
- **Щоденник солу.** Опівночі ШІ пише запис від першої особи, набуває нової риси характеру
  і ставить мету на завтра. Мета й риси впливають на рішення наступного дня
  (`d` — відкрити щоденник; копія пишеться в `logs/diary-<мозок>-<seed>.md`).
- **Друга вціліла — Ліра.** З'являється після сигналу SOS. Її побут веде utility-AI без
  виклику моделі: п'є, їсть, спить у капсулі, носить волокно у сховище. ШІ вмикається лише
  для розмов. У неї є довіра, симпатія й прохання; їй можна `give` їжу.
- **Рефлекси.** Якщо модель збоїть, герой діє «інстинктивно» за правилами і не завмирає.

## Графіка: спрайти, анімація, 2D і 2.5D

Окрім термінального ASCII, у гри є графічний клієнт (pygame). Усе там намальовано
піксель-артом: кожен тайл, істота, предмет, NPC, раса, локація, ефект та іконка HUD.

```bash
uv run wilds --gfx                                   # Тау-7, Claude
uv run wilds --gfx --brain scripted --view iso       # ізометрія 2.5D, без ШІ
uv run wilds --chapter cyberpunk --gfx --brain scripted
uv run wilds --brain scripted --headless 800 --shot shot.png   # кадр у PNG без вікна
```

- **Вигляд:** `2d` — вид 3/4 зверху з гранями скель, перегородок і будівель, `iso` —
  ізометрія з об'ємними блоками та силуетом міста. Перемикає клавіша `i`.
- **Живий світ:** зміна доби з кольоровим небом, джерела світла (обігрівачі, капсула,
  неон, вікна), світні пікселі й ореоли, туман війни, пилова буря, дощ у місті,
  нічні спори. Анімації ходьби, роботи, атаки, сну й розмов, плавний рух між
  тайлами, числа шкоди й лікування, бульбашки думок і реплік.
- **Клавіші:** `пробіл` — пауза, `+`/`-` — швидкість, `[` `]` або коліщатко — масштаб,
  `i` — 2D/2.5D, `d` — щоденник, `g` — «око бога», `m` — мінікарта, `Tab` — панель,
  `s` — зберегти, `n` — новий світ, `F11` — повний екран, `F12` — скріншот, `h` — довідка.

Спрайти описано кодом у `src/wilds/gfx/sprites/`: текстові сітки з легендою кольорів
спільної палітри. Маніфест (`gfx/manifest.py`) будується з енумів гри, тож тест падає,
якщо в нового об'єкта немає спрайта.

```bash
uv run wilds-sprites --strips --gif --out sprites_export   # контакт-листи, PNG-стрічки, GIF
uv run wilds --gfx --sprites my_sprites                    # PNG з тими ж іменами підміняють вбудовані
```

Намальуйте свої PNG (Aseprite або генератор піксель-арту) у форматі з `png/` і
покладіть у теку, передану як `--sprites`. Гра підхопить їх замість вбудованих.
Як додавати спрайти, описано в `.claude/skills/sprite-artist/SKILL.md`.

## Уся гра однією командою

```bash
uv run wilds --campaign --gfx            # вікно зі спрайтами: Тау-7, потім Тінемісто
uv run wilds --campaign                  # те саме в терміналі
uv run wilds --campaign --brain scripted --headless 40000   # без інтерфейсу, безкоштовно
```

`--campaign` веде героя крізь обидві глави:
- Тау-7 іде до порятунку.
- Порятунок пише спадок у `legacy/`, і те саме вікно (термінал, headless-прогін)
  продовжує кіберпанк-главою з тим самим героєм.
- Смерть повторює главу на новому світі.
- Сплачений борг завершує кампанію, після чого в графічному клієнті починається нова.

Без `--campaign` глави запускаються окремо, а друга бере найновіший спадок:
`uv run wilds --chapter cyberpunk`.

## Журнали

Усі файли пишуться в теку `--log-dir` (типово `logs/`, `--log-dir ""` вимикає запис):

| файл | що там |
|---|---|
| `events-<мозок>-<seed>.log` | **повний журнал гри** в усіх режимах, для кампанії одним файлом на обидві глави. Містить кожну подію світу (як у «Бортовому журналі»), кожне рішення мозку з причиною, знімок стану героя після кожного рішення, підсумок кожної дії, збереження, кінці глав і переходи кампанії |
| `events-cyberpunk-<мозок>-<seed>.log` | те саме для окремого запуску кіберпанк-глави |
| `claude-<дата>.jsonl`, `codex-<дата>.jsonl` | кожен виклик ШІ: тік, тип, модель, затримка, повний промпт, відповідь, помилка |
| `diary-<мозок>-<seed>.md`, `diary-cyberpunk-…md` | щоденник героя |

Інші файли: спадок у `legacy/`, збереження в `saves/` (лише Тау-7), скріншоти (F12)
у `screenshots/`.

## Мозок героя

| `--brain` | що це | потрібно |
|---|---|---|
| `claude` (типово) | Claude через `claude -p` | залогінений Claude Code (підписка, без API-ключа) |
| `codex` | OpenAI Codex через `codex exec`, типово **GPT-5.6-Luna** | залогінений Codex CLI |
| `scripted` | правила без ШІ (грає ефективно, але сухо) | нічого, безкоштовно |

```bash
uv run wilds                                  # Claude Haiku
uv run wilds --brain codex                    # Codex, gpt-5.6-luna
uv run wilds --brain codex --model gpt-6-luna --effort medium
uv run wilds --model sonnet --think           # розумніше, але повільніше
uv run wilds --brain scripted --seed 42 --speed 4
uv run wilds --brain codex --headless 1440    # сол без інтерфейсу; наприкінці метрики
```

Рішення займає близько 7 с. Плюс 1 виклик на щоденник за сол і кілька на розмови.
Для рутинних справ ШІ може обрати макродію (`routine night`, `routine supplies`), яку
далі виконує код.

Клавіші: `пробіл` — пауза, `+`/`-` — швидкість, `d` — щоденник, `s` — зберегти,
`g` — «око бога», `n` — нова планета, `q` — вихід (теж зберігає).

Збереження: `saves/<мозок>-<seed>.wsav`. Гра автоматично зберігається щосолу (після запису
в щоденнику) і при виході через `q`. Продовжити: `uv run wilds --continue` (останнє
збереження) або `uv run wilds --load saves/claude-255185.wsav`.

Друга глава (місто) зберігається в `saves/cyber-<мозок>-<seed>.csav` так само: `s`,
щодня після щоденника і при виході — у графічному клієнті (`--gfx`) та headless-режимі.
`--continue` сам обирає главу за найновішим збереженням, тож
`uv run wilds --continue --gfx --view iso --brain codex` продовжить місто, якщо воно було останнім.

## Як це влаштовано

ШІ **не натискає клавіші**. Він обирає *намір* із меню з 21 дії, а код виконує його
покроково. Модель питають знову лише тоді, коли дія завершилась або її перервала подія:
загроза, удар, падіння показника, ніч, попередження режисера. Спостереження подає простір
двічі: маленьке ASCII-вікно 25×13 і явні вектори `dx/dy`, бо на сирій сітці LLM
погано рахують відстані. Дизайн спирається на дослідження з `docs/research/`:
BALROG, Generative Agents, Voyager, RimWorld/L4D AI Director, Concordia.

| модуль | що робить |

## Розділ 2: кіберпанк-сага (усі 6 етапів)

Коли герой рятується з Тау-7, гра пише невеликий «спадок» (ім'я, риси, щоденник,
стартові нуєни з проданих артефактів) у `legacy/<мозок>-<seed>.json`. Друга глава
читає цей спадок і продовжує історію того самого персонажа вже в кіберпанк-місті,
за мотивами Shadowrun (`docs/research/shadowrun-reference.md`, дорожня карта й стан
реалізації всіх етапів — `docs/superpowers/specs/2026-09-24-cyberpunk-saga-design.md`).

```bash
uv run wilds --chapter cyberpunk                     # найновіший спадок з legacy/
uv run wilds --chapter cyberpunk --no-legacy          # почати без спадку (випадкова раса, 200¥)
uv run wilds --chapter cyberpunk --brain codex --seed 11
uv run wilds --chapter cyberpunk --headless 2000      # без інтерфейсу
```

**Сюжет:** корпорація, що «врятувала» капсулу з Тау-7, вважає це послугою й вішає на
героя борг (типово 5000¥). Клавіші ті самі (`простір`, `+`/`-`, `d`, `g`, `q`).

| Етап | Що додає |
|---|---|
| 1. Хаб | Раси (5 метатипів Shadowrun), есенс/кібервеа, NPC з довірою/симпатією, `talk`/`trade`, спадок із Тау-7 |
| 2. Контракти | Фіксер видає кур'єрську роботу (`request_job`/`complete_job`) — головне джерело нуєнів |
| 3. Райони | Три райони міста (`travel`), кожен зі своїми NPC; місця в іншому районі відхиляються з підказкою |
| 4. Космос | Корабель (паливо/корпус), `launch` до орбітальної станції чи форпосту за містом |
| 5. Фракції | Репутація з фіксерами/торговцями/бандами — знижки/надбавки до 15% на ціни |
| 6. Кібервеа+ | Альфа-градація імплантів: дорожче нуєнами, вдвічі дешевше есенсом |

**Дії:** `go_to`, `explore`, `travel`, `launch`, `refuel_ship`, `talk`, `trade`,
`request_job`, `complete_job`, `pay_debt`, `use`, `rest`. `pay_debt` до нуля завершує
главу («вільний») — з доходом від контрактів це реально досяжно в межах перших днів.

Свідомо не реалізовано (як і планувалось): магія/Пробудження, повна Матриця-мінігра з
ICE, тактичний бій з укриттям і Action Points — бій лишається поза межами гри, як і в
розділі 1, гравець ним не керує.

### Ставки й напруга (додатковий раунд, 2026-09-25)

Курʼєрський цикл із контрактів був занадто безпечним «локальним оптимумом» —
виправлено додаванням реальних ставок (деталі: той самий spec-документ вище,
розділ «Додатковий раунд»):

- **District Heat + Fail Forward** — кожен район має теплоту (0-100); завершення
  роботи чи покупка кіберве піднімає її, час знижує. `complete_job` тепер може
  вийти повним успіхом, «успіхом-з-ціною» (побиття) або провалом (без оплати,
  важкий удар) — перше реальне джерело шкоди для hp за всю главу.
- **Кулдаун фіксера + утримання** — 3 роботи поспіль від одного фіксера дають
  йому 4-годинну паузу; щоденне утримання знімається з нуєнів або йде в борг.
- **Транші боргу + колектори** — пропущений раз-на-3-дні мінімальний платіж
  викликає ворожого колектора в домашньому районі.
- **Багатовісна напруга Director-7** (обидві глави) — вісь "новизни" на основі
  ентропії дій (`Metrics.action_diversity`) нарешті замкнула цикл цієї метрики;
  правило безпеки не дає плановому піку статись при критично низькому hp.
- **Модифікатори районів + поріг ворожості** — Доки повільніші й тихіші,
  Корпоративний ряд гучніший і дорожчий; дуже негативна репутація з бандами
  іноді закінчується засідкою гангстера.

## Розділ 3: Мулгор у справжньому масштабі (Azeroth)

Мулгор 5450×3633 ярдів (тайл = 2 ярди) з даних публічної вікі й карти зони, у 2.5D: плавні пагорби, сосни,
озеро Стоунбулл, табори тауренів і Тандер-Блафф. Світ живий: звірі пасуться, NPC на місцях, день змінює ніч.

```bash
uv sync
uv run wilds --chapter azeroth --explore                     # просто оглянути Мулгор (герой стоїть, його не вбити)
uv run wilds --chapter azeroth --explore --start "Thunderhorn Water Well"
uv run wilds --chapter azeroth                               # герой на правилах проходить квести Мулгору
uv run wilds --chapter azeroth --shot shot.png --start "Great Gate"   # кадр без вікна
```

Керування: WASD або перетягування мишею рухають камеру, клік по мінікарті переносить, цифри 1–9 телепортують
по місцях, `f` стежить за героєм, `i` перемикає 2.5D і вид 3/4, `[` `]` або колесо змінюють масштаб,
пробіл пауза, `+`/`-` швидкість, `n` імена, `m` мінікарта, `h` довідка.
Арт описано в `docs/azeroth/`, нотатки за референсами в `docs/azeroth/reference-notes.md`.
